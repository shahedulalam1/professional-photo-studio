# প্রিন্ট ফরম (Professional Photo Studio)

ছবি কেটে, ঠিক করে সরাসরি প্রিন্ট করার সহজ টুল।  
আইডি কার্ড, পাসপোর্ট ছবি এবং ফুল পেজ ছবি এক জায়গা থেকে প্রিন্ট করা যায়।

---

## ফিচারসমূহ

- **আইডি কার্ড** — সামনে ও পেছনের ছবি একসাথে প্রিন্ট
- **পাসপোর্ট / স্ট্যাম্প ছবি** — বিভিন্ন সাইজ সাপোর্ট (৪০×৫০, ৩৫×৪৫, ২×২ ইঞ্চি ইত্যাদি)
- **ফুল পেজ ছবি** — A4 পেজে যেকোনো ছবি প্রিন্ট
- ছবি ক্রপ, রোটেট ও জুম করার সুবিধা
- ব্যাকগ্রাউন্ড পরিবর্তন (সাদা, নীল, লাল ইত্যাদি)
- Dark Mode সাপোর্ট
- মোবাইল ও ডেস্কটপ দুটোতেই ভালোভাবে কাজ করে
- প্রিন্ট করার সময় অপ্রয়োজনীয় জিনিসপত্র লুকিয়ে যায়

---

## কিভাবে ব্যবহার করবেন

1. [index.html](index.html) ফাইলটি ব্রাউজারে খুলুন
2. উপরে থেকে মোড সিলেক্ট করুন (আইডি কার্ড / পাসপোর্ট / ফুল পেজ)
3. ছবি আপলোড করুন
4. প্রয়োজন অনুসারে ক্রপ, রোটেট বা সাইজ অ্যাডজাস্ট করুন
5. **প্রিন্ট** বাটনে ক্লিক করুন

> কোনো ইনস্টলেশন বা সার্ভার লাগে না। সরাসরি ব্রাউজারে চলে।
